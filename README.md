# chicago-311-weather

Calendar-blind: can a model learn Chicago's seasonal 311 complaint calendar from daily weather alone, without ever being given the date?

Status: registered. No data has been retrieved. See PREREG.md.

Files: PREREG.md (the registration, not edited after commit), PREREG_MAPPING.md (category → request-type strings), DEVIATIONS.md (every departure from the registration), NOTES.md (data problems as found), results/ (written once by the study run), viz/ (offline visualizations).
